## Результаты

Измерены 132 из 132 конфигураций: 63 для калибровки и 69 для независимой проверки. В этой основной сетке OOM не наблюдался; максимальный пик выделенной памяти — 5.75 GiB. Дополнительно выполнен отдельный поиск реальной границы OOM (ниже).

| Величина | Медианная относительная абсолютная ошибка на отложенных точках |
|---|---:|
| Время | 33.41% |
| Память | 34.95% |
| Энергия | 30.29% |

Модели приближённые: память не включает workspace cuDNN, а постоянные параметры времени не описывают все скачки производительности. Причины расхождений и ограничения рассмотрены в [обсуждении результатов](hw1/results/DISCUSSION_RU.md).

## Дополнительный эксперимент: граница OOM

На одной Tesla T4 при S=512 увеличен батч за пределы основной сетки. Выполнены 18 проб для 14 разных батчей; 9 проб завершились настоящим `torch.cuda.OutOfMemoryError`. Каждый запуск — в новом процессе, без искусственного ограничения памяти.

- **B=867 — OK; B=868 — OOM.** Обе точки проверены по три раза, исходы повторились.
- Формула памяти без подгонки предсказывает первый OOM при **B=877** по полной памяти GPU и при **B=870** по фактически свободному бюджету перед входом.
- Смещение порога по полной памяти — 9 элементов батча, или **1.04%**. Непосредственно у границы пик успешного прохода при B=867 составляет 14.41 GiB.
