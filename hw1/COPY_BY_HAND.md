# Краткий вариант для переписывания (2–3 страницы)

## 1. Допущения

FP32, eval(), inference_mode(), S кратно 16, MAC=2 FLOPs. Conv без bias, Linear с bias. ReLU inplace. Сравнения ReLU/MaxPool не считаю арифметическими FLOPs. BatchNorm в выбранной архитектуре нет. Внешний вход x сохраняется весь forward. GPU используется одна.

Выходы Conv: 32(S/2)², 64(S/4)², 128(S/8)², 256(S/8)², 256(S/16)², 512(S/16)². После первой Conv стоит MaxPool с выходом 32(S/4)²; в конце GAP, Linear 512→256, ReLU, Linear 256→100.

## 2. FLOPs

F_conv = 2B·H_out·W_out·C_out·C_in·k².

По слоям: (2352 + 6400 + 2304 + 1024 + 4608 + 1024)BS² = 17712BS².

GAP: 512B·(S/16)² = 2BS² (n−1 сложений + деление на каждом канале).

Linear: 2B(512·256+256·100)+(256+100)B = 313700B.

**F(S,B)=B(17714S²+313700).**

## 3. Память

P=4704+51200+73728+32768+589824+131072+131072+25600+356=1040324 параметра, W=4P=4161296 байт.

Пик около MaxPool: исходный вход 12BS² байт, выход Conv1 32BS², выход MaxPool 8BS², временные индексы int64 16BS².

**M(S,B)≈4161296+68BS² байт.**

Это оценка без подгонки. Фактический max_memory_allocated может быть выше из-за workspace cuDNN и округления аллокатора. OOM предполагаем, если M превышает память GPU; отсутствие такого превышения не гарантирует, что точка поместится.

## 4. Трафик и время

Для Conv/Linear Q_i=4[B(A_in+A_out)+W_i]. Для ReLU Q_i=8BA_i. Для MaxPool Q_i=56BS², включая запись индексов. Для GAP Q_i=4B(2S²+512).

Сумма: **Q(S,B)=380BS²+8592B+4161296 байт.** Это модель логического трафика без кэша и workspace.

17 операторов: 6 Conv+7 ReLU+MaxPool+GAP+2 Linear.

**T(S,B;θ)=17τ+Σ_i max(F_i/C,Q_i/D).**

τ — секунды на запуск; C — FLOPs/с; D — байт/с. На малых задачах доминирует 17τ. Слой memory-bound, если F_i/Q_i<C/D, и compute-bound в обратном случае. Разные слои могут иметь разные режимы.

θ подбираю на базовой сетке, минимизируя Σ(log T_pred−log T_real)². Все случайные S/B оставляю для validation. T_real — медиана 9 синхронизированных wall-clock измерений после 3 прогревов.

## 5. Энергия

**E(S,B;θ_E)=αF(S,B)+βQ(S,B)+P₀T(S,B;θ).**

α — Дж/FLOP, β — Дж/байт, P₀ — Вт. Коэффициенты ≥0; fit относительной ошибки только на train, θ фиксирован.

E_real=ΔE_GPU/N по NVML energy counter; если недоступен, E_real≈Σ(P_j+P_(j+1))(t_(j+1)−t_j)/(2N). Целевое время серии ~1.2 с; фактическое 0.894–1.745 с, потому что последовательные вызовы быстрее отдельных синхронизированных. Это энергия всей одной GPU, idle не вычитается. Серия даёт среднее при устойчивой нагрузке; измерение одиночного короткого forward слишком шумное.

Ограничения: выбор cuDNN kernels, кэш, частоты/температура GPU, workspace, шум/дискретность датчика и корреляция F и Q. Параметры являются эффективными, не независимыми физическими константами.
