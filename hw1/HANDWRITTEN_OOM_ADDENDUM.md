# Дополнение к рукописной работе: проверка OOM

В основной сетке из 132 точек OOM не возник. Поэтому дополнительно увеличивал батч при $S=512$ на одной Tesla T4. Получена граница: $B=867$ — успешно, $B=868$ — OOM. Обе точки проверены по три раза в новых процессах, без искусственного ограничения памяти.

По формуле $M(512,B)=4161296+68\cdot512^2B$ и полной памяти GPU $G=15636037632$ байт:

$$
B_{\mathrm{OOM,pred}}=
\left\lfloor\frac{G-4161296}{68\cdot512^2}\right\rfloor+1=877.
$$

Первый OOM в поиске получен при $B=868$: прогноз завышен на 9, то есть примерно на $1.04\%$. При учёте свободного бюджета памяти вместо полной ёмкости прогноз — $B=870$. Формула не учитывает все временные буферы и накладные расходы CUDA/аллокатора; поэтому фактический OOM может возникнуть раньше. Коэффициенты памяти не подгонялись.
